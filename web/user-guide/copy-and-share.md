# Copying & Sharing Verses

## Opening the copy dialog

- Press <kbd>Ctrl</kbd>+<kbd>C</kbd> (<kbd>Cmd</kbd>+<kbd>C</kbd> on a Mac) while reading, with no text selected. If text is selected, <kbd>Ctrl</kbd>+<kbd>C</kbd> copies the selection instead.
- Or right-click a verse in the reading area and choose *Copy Passage…*.

Then the *Copy Verses* dialog opens.

## The copy dialog

The dialog has three parts: a reference, a format, and a live preview.

### Choosing what to copy

The *Reference* box holds the passage to copy. It starts with the verse you were reading. Type over it to copy something else: a verse, a range such as `John 3:14-18`, or a chapter.

### Choosing a format

- **Standard** — the text with its reference.
- **Plain** — the text and reference, with no other formatting.
- **Paragraph** — the passage as prose with paragraph breaks preserved, instead of one line per verse.
- **Full** — one verse per line, each with its number.
- **Advanced** — each option as an individual switch.

*Advanced* allows you to specify several individual options for copying, such as whether each verse is on a new line, paragraph breaks, verse numbers, chapter headings, words of Christ in red, the translation abbreviation, and the reference position (beginning, end, or none).

There is also a template option. A template defines a custom layout using placeholders for the reference, book, chapter, translation, and verse count, and loops over verses or paragraphs. Templates are not saved, so keep a copy of your template text elsewhere if you want to reuse it.

### The Markdown option

The Markdown option applies to any format.  It is optimized for copying text into a Markdown document (a special kind of plain text document that has some formatting options).

### Live preview

The preview shows exactly what will be copied. Click *Copy to Clipboard*; the button changes to *Copied!*. The selected format is remembered.
