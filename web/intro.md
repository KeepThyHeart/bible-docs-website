# {{productName}} for the Web

{{productName}} for the Web is a Bible reading and study app that runs in your browser.s

![The full app in desktop layout: Bible text on the left, study and commentary panels on the right, header visible](/img/web/intro-desktop-layout.png)

## What you can do

- Read the Bible in any translation that the site provides.
- Study a passage with commentaries, cross-references, topical indexes, and Greek and Hebrew tools, shown beside the text.
- Search by keywords (*Standard Search*) or by meaning (*Ideas Search*).
- Use the app on a desktop, tablet, or phone. The layout adapts to the screen size.

![The app on a phone screen, Bible text with the bottom navigation bar](/img/web/intro-mobile-phone.png)

## Open Source

{{productName}} is open source, which means that the code running it is free for anyone to download and modify.  Anyone can host a Bible reader website.  The site operator would do the following:

- Download the modules (Bible translations, commentaries, etc.)
- Configure which features are turned on or off (e.g., Ideas Search takes a lot more memory and processing than keyword search)

If a feature described in this guide is missing, it may be turned off on that particular site.
