# Copying & Exporting

## Copying verses

To copy in your default format, select a verse or range and press <kbd>Ctrl</kbd>+<kbd>C</kbd>, or right-click and choose the plain copy command. To choose the format, right-click and choose the copy command that opens the copy dialog.

![The verse context menu, with its copy commands among the other actions](/img/desktop/copy-verse-context-menu.png)

## The copy dialog

The copy dialog has:

- Format templates. Choose a preset or create your own.
- Switches to include or exclude the reference, verse numbers, and translation name.
- The verse range, which you can change without closing the dialog.
- A live preview of what will be copied.

![The copy dialog with its format options and the live preview of the result](/img/desktop/copy-dialog-preview.png)

## Custom templates

The template editor creates custom formats. A template sets the arrangement of the reference, verse numbers, text, and translation name. Examples:

- Reference after the text: `"For God so loved the world…" (John 3:16, KJV)`
- Reference first: `John 3:16 — For God so loved the world…`
- Verse-numbered blocks
- Text only, with no reference

![The template editor, with a custom citation format being built](/img/desktop/copy-template-editor.png)

## Exporting your notes

*File → Export My Notes* saves your notes, highlights, and other data to an encrypted, password-protected file. The file can be restored in Merge or Replace All mode. See [Backup & Restore](./backup-and-restore.md).

## Printing

Print using your operating system's print facility. Simple mode with the study pane collapsed gives the cleanest output. See [Personalizing](./personalizing.md) for zoom and text size.

## Copyright

Bible translations, commentaries, and dictionaries are separately licensed. Some are in the public domain. Many modern translations limit how much may be quoted and require attribution.

:::warning
This Bible app does not check these terms, and so if distributing quoted text, just be sure it's allowed for that translation, if it's copyrighted.
:::
