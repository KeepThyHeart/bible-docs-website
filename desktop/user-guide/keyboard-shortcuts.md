# Keyboard Shortcuts

This list is also available in the app under *Help → Keyboard Shortcuts*, or with <kbd>Ctrl</kbd>+<kbd>/</kbd>.

:::note
On macOS, use <kbd>Cmd</kbd> wherever <kbd>Ctrl</kbd> is listed below.
:::

## Navigation

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Go to verse |
| <kbd>Alt</kbd>+<kbd>Up</kbd> | Previous chapter |
| <kbd>Alt</kbd>+<kbd>Down</kbd> | Next chapter |
| <kbd>Alt</kbd>+<kbd>Left</kbd> | Navigate back in history |
| <kbd>Alt</kbd>+<kbd>Right</kbd> | Navigate forward in history |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Focus the search bar |

## Search

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find in current pane |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Search all modules (advanced search) |
| <kbd>Escape</kbd> | Close dialog or cancel search |

## Editing and annotation

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy selection |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cut selection |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Highlight selection |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Toggle underline on selection |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Add note on selected verse |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Bookmark the selected verse (again to remove) |

## View

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | Zoom in |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom out |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Reset zoom to actual size |

## Application

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> or <kbd>F1</kbd> | Open the command palette |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Open Preferences |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | Show keyboard shortcuts |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Toggle developer tools |

## The command palette

The command palette (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> or <kbd>F1</kbd>) searches all commands by name, including commands without a shortcut. For example, type "module" for the Module Manager, "theme" to switch themes, or "export" to back up your notes. Commands also have aliases: "settings" finds Preferences, and "docs" finds the documentation.

You can also open the palette by typing `/` in the search bar.
