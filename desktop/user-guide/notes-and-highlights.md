# Notes & Highlights

Modules are read-only. Everything you create (highlights, verse notes, documents, journal entries, and prayer lists) is stored in a separate database and backed up independently of modules.

## Highlighting

Select one or more verses in the Bible pane, right-click, and choose the highlight command. Pick a color: yellow, green, blue, pink, orange, or another. To change a highlight, pick a different color. To remove it, right-click and choose the command that clears it.

![A passage with several verses highlighted in different colours](/img/desktop/notes-highlighted-verses.png)

### The floating toolbar

Selecting text within a verse shows a floating toolbar with highlight, underline (<kbd>Ctrl</kbd>+<kbd>U</kbd>), and clear formatting. Use it to mark part of a verse. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> highlights the current selection.

## Verse notes

Verse notes are attached to a verse and appear in the *Verse Notes* tab. To add one, select a verse and start a new note in that tab, or right-click the verse and choose the command that adds a note (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd>). Notes save automatically as you type. Verses with notes show a note icon in the Bible pane.  A verse's notes appear again whenever you return to that verse.

![A verse note open in the Notes pane beside the Bible text](/img/desktop/notes-verse-note-open.png)

## Documents

Documents are not tied to a specific verse.  They can include things like sermon outlines, research, topical studies, or lesson plans. In the *Documents* tab, start a new document and give it a title. Documents also save automatically, are organized into folders, and may be tagged to help with organization.

## Journal

The *Journal* tab holds dated entries. Each new entry is stamped with the current date.

<!-- shot: notes-journal-tab — The Journal tab, with its dated entries -->

## Prayer lists

The *Prayer* tab tracks prayer requests.

- You can keep several lists, each with a name and an optional color. Switch lists with the selector at the top of the tab.
- Each request has a title and content.
- Marking a request as answered moves it to the Answered section.
- Drag requests to reorder them. Delete requests you no longer need.
- Requests can have linked Bible verses.

![The Prayer pane with a list of requests](/img/desktop/notes-prayer-tab.png)

## The editor

Notes, documents, journal entries, and prayer requests use the same text editor. It supports:

- Bold, italic, underline, and strikethrough
- Three heading levels
- Bulleted and numbered lists, block quotes, tables, images, and task lists
- Tags

Scripture references typed in the editor become links that navigate the Bible pane.

![The note editor’s formatting toolbar, with formatting applied to the text below it](/img/desktop/notes-editor-toolbar.png)

## Finding notes

The search box in the notes tree matches note titles and references. `John 3:16` finds notes attached to that verse; `Genesis 1` finds notes in that chapter. Tags group notes across passages.

## Your data

Notes, highlights, and sessions are stored separately from modules, so updating or uninstalling a module does not affect them. To back them up, use *File → Export My Notes*; see [Backup & Restore](./backup-and-restore.md). For copying text out of the app, see [Copying & Exporting](./copy-and-export.md).
